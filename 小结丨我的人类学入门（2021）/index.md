# 小结丨我的人类学入门（2021）

今年寒假（二月份）的时候，我开始有了学点人类学的想法。好像那时距牛津大学的项飙走红不久，我在油管和哔哩哔哩、公众号上偶尔会刷到有关项飙的东西，但都没有点进去系统地去看。

正经的动机是为了可能有的研究生复试做些准备。因为我的目标导师虽是传播学者，但他出的几本书基本是以人类学田野调查为方法的。他强调（乡村）传播学与人类学民族志的结合。

从2月份开始，一直到6月初期末季开始之前，我把课余的大部分时间花在了对人类学的学习上。尽管期间接到了差三分进复试的通知，我也没有中断这个过程。

我是纯正的理科生，高中和大学都是学的理科，自觉对一些社会学概念和方法的储备都十分匮乏。在入门之路上，我借助了很多网络资源和电子资源，听了一些老师的讲课，看了一些推荐的书目，受益匪浅。我想着对这次入门之旅做一个小结，既反省不足，也为未来做个参考。以下按照老师/名家、课程、书目、平台这样的分类做一个清单式的总结，和大家分享。

# 1 老师/名家

潘天舒

博士生导师。复旦本科，哈佛人类学博士。2007年至今担任复旦-哈佛医学人类学合作研究中心中方主任，2012年至今担任复旦大学社会发展与公共政策学院教授。

我在线下旁听了潘老师一个学期的《文化人类学》课程。不像中山大学直接有一个“社会学与人类学学院”，复旦没有人类学系，也没有民族学系，只是在社政学院里面开设了人类学相关的课程，而潘老师和另外一两位老师就承担了讲授这几门人类学课程的责任。上课时，潘老师基本是按照 人类学定义、研究方法、经济人类学、政治人类学、语言人类学、亲族关系、婚姻制度、艺术人类学 这样的线索来讲授的。因为文化是一个内涵极为广阔的概念，所以文化人类学几乎无所不包，除了偏向生物学的体质人类学和偏向化学等学科的考古人类学这两个人类学的分支。

潘老师讲课的素材十分丰富，能够旁征博引，并且给课后留了充足的阅读材料。他还戏言自己的这套课程PPT在考研黑市上可以卖六十多块钱。

潘老师实际上对医学人类学有比较深的介入，比如尝试从患者/当事人的角度，而不是医生等其他人的角度去理解病痛，区分illness和disease。医生看病看的是disease，而病人的病是illness。再比如，我们大多数时候关心怎么对病人进行照护，却忽视了照护是怎么被接受的。另外他这两年还在牵头复旦、哈佛与江苏产业研究院合作探索适老技术，研究养老问题。同时进行的还有与此相关的每年的暑期学校。对应的公众号是“复旦人类学”，经常发一些文章，值得一看。

潘老师在一席有个演讲可以看看，标题是《用猎奇的心态凝视自己》。

项飙 

1972年生于温州，牛津大学人类学教授。本科论文《悬浮群体》、硕士论文《跨越边界的社区》、博士论文《全球猎身》。我重点阅读的是吴琦和他的对谈《把自己作为方法》和他的硕士论文《跨越边界的社区》，还有一些是项飙在媒体和公众号上的文章或发言。

项飙提出的或阐述的一些概念比较有意思，比如悬浮、乡绅、中心和边缘、个人的经验、人的再生产。他描述的“乡绅”能把自己那个村的情况摸得很透，能够把多数人活在这个系统里面的味道讲出来，能够说清楚这个系统是怎么靠里面的人和事叠加出来，而不是靠外在的逻辑推演。这样的“乡绅”在我看来像是一种情感寄托，实际上相当于古代中国农村的那种良绅，可惜在现代化浪潮下变成了土豪劣绅。而现在的人大代表又多大程度称得上是地方的乡绅？如果真有这样的乡绅，他能不能和乡村振兴联系起来？

他讲的“中心”和“边缘”的区别比较吸引我。他说家乡是古时乡绅的最重要的意义世界。“考上状元、当宰相当然很好，家眷常常还留在家乡，而且一不当官，立马回乡。所以有人说，中国开始现代化的象征之一，就是官僚退休不回家乡了。城市和农村之间的循环性的关系被打断了。告老不还乡，点出了中国的中心和边缘的关系、城市和农村的关系、知识分子和普通群众（主要是农民）的关系，在现代发生了什么变化。”

项飙在北大读书期间就开始在北京的浙江村调研，后来依此写成硕士论文《跨越边界的社区》，堪称移民研究的典范。这本书描写得很细，分析得也很细，下了很大功夫，体现出琐细而真切的人类学关怀。他在十三邀里坦言这也许是他这一辈子再也难以超越的作品。网上有他的一些访谈和讲座视频，很方便就能找到。

艾伦·麦克法兰

剑桥大学社会人类学系教授。老爷子曾经在尼泊尔的喜马拉雅山区有三十年的田野经验，经历十分丰富。我是在哔哩哔哩上看他的剑桥人类学课程，系统地了解了经济人类学这一分支，可惜现在找不到当时做的笔记了。他自己有一个个人网站，在谷歌上搜索就能找到，上面应该有很多学习资料。另外他也有自己的油管账号，就叫Prof Alan Macfarlane，更新频率还挺高。

老爷子的著作有《绿色的金子》《玻璃的世界》《英国个人主义的起源》《日本镜中行》。

大卫·格雷伯

疫情期间去世的一位人类学家，无政府主义者。著作主要有《狗屁工作》《债：5000年债务史》。

在他逝去之后，不少媒体都发文纪念他，称他是一位值得称赞的社会活动家。我没有读过他的书，我只是在随机波动的一期播客里了解到这位人物，在一些只言片语中对他有个模糊印象，打算之后寻个机会去读他的书。

费孝通

费老的重要性无需多言。他是中国社会学、人类学的奠基人之一，是人类学家马林诺斯基的弟子，在后者的指导下完成了《江村经济》。

费老的三次田野分别是广西金秀瑶山（期间，妻子不幸身亡）、江苏的江村（姐姐家）、云南禄村。后来，费老还为新中国成立之初的民族识别工作做了杰出贡献。费老的著作主要有《乡土中国》《生育制度》《乡土重建》等。其中他在《乡土中国》提出了著名的“差序格局”概念。

晚年时，费老还回应同门师兄英国人类学Edmund Leach的质疑，表示自己投入人类学是为了推动中国社会发展，志在富民。并且费老提出了自己的重要观点：研究者自己本身就是研究方法，并不是要去掉自己的主观性才能拿到研究成果。（项飙的“个人经验”和这里相呼应了）

值得一提的是，费老的姐姐费达生一生在开弦弓村（江村）从事蚕桑丝绸技术的推广。相较于80年代乡镇企业热，费达生二十年代就深入农村，很早就走上了推动乡村工业化的道路。这是近代以来中国乡村建设事业的一部分。

克利福德·格尔茨 (Clifford Geertz)

1926年出生，美国人类学家，解释人类学的倡导者。他曾在印尼爪哇等地做田野调查，提出了 **深描（thick description）、内卷(involution)、地方性知识(local knowledge）**等概念。著有《文化的解释》等。

其中，深描成为了后来人类学最热门的名词。这个词是格尔茨从美国哲学家赖尔那里借用的，赖尔曾举过一个“眨眼”的例子来说明深度描述与浅描的区别，有兴趣可以谷歌/百度一下 。

内卷。这一人类学术语如今疯狂出圈，最早是格尔茨在1963年的**《农业内卷化——印度尼西亚的生态变化过程》一书中提出** ，与内卷（involution）对应的则是进化（evolution），暗示了内卷是某种意义上的退化。格尔茨在实地研究中发现,在爪哇岛和外岛之间存在着二元的发展,外岛的一些地区借助于技术,生产越来越向资本密集型方向发展；而爪哇岛的一些地方则不断地向劳动密集型方向发展。爪哇岛聚集了印度尼西亚2/3的人口,主要从事粮食生产和小型手工业;而外岛散布在爪哇以外的广阔区域内,殖民者的进入使那里产生了高效率、大规模、主要用于出口的工业。爪哇人由于缺乏资本,土地数量有限,加之行政性障碍,无法将农业向外延扩展,致使劳动力不断填充到有限的水稻生产中。在概括这一过程的时候,格尔茨使用了“农业内卷化”概念。 

此外，格尔茨也曾给“文化”下了一个著名定义，**“文化是指由历史上传承下来并体现于象征中的意义模式(pattern of meanings),也指在各种象征形式中表达的、承继下来的概念系统,依据这样的象征形式 ,人们交流、维持和发展他们有关生活的知识和对待生活的态度**”。有点向韦伯致敬的意味，“文化是意义的网络”。

《影像人类学》-中央民族大学朱靖江

这个课程在bilibili上有。朱靖江老师从 视觉与人类学联姻的缘起、视觉人类学发展史、视觉人类学在中国的发展历程、视觉人类学的研究方法、新趋势新发展 等几个方面展开讲授，讲得比较清晰全面。

其中朱老师在课程中穿插推荐了很多有意思的人类学影片、纪录片，能找到资源的话可以去看看，应该是非常有价值的。

# 3 书目

《西太平洋上的航海者》马林诺斯基

1922年出版。书中详细描述了一种特殊的交换制度「库拉制度」。马林诺斯基因为战争的缘故，在新几内亚的特罗布里恩群岛与土著一起生活了几年，在此期间开展自己的田野工作，由此成书。后来，他的这种民族志式的科学研究范式、参与式观察成为人类学的主流。学者们将其奉为圭臬并前赴后继，去到世界各地开展田野工作。

马林诺斯基是功能主义人类学的开创者，也是费孝通的老师。他的这本书基本上在任何人类学入门书单中都会被推荐，绝对是经典。

《忧郁的热带》列维斯特劳斯

这本书1955年出版，是一本大部头，读起来不像是民族志，而是一篇游记散文，其中又穿插着作者发出的一些思考。若是单纯旅行游记，列维斯特劳斯对其奇异艰辛的旅程描写得细致入微；作为人类学考察手记来看，他对巴西高原和亚马逊热带雨林地区的土著人进行了事无巨细的调查。

最令人印象的深刻的是他时不时的“放飞自我”，发出一些哲学思考和自我省察。我读的是三联书店2003年的译本，有些地方翻译得不到位，有可能的话可以找个更好的版本再读。

《我的凉山兄弟》刘绍华（台湾）

这本书我还没来得及读，但是据说十分值得阅读。

百度百科介绍“所描述的是二十一世纪初的中国，世人讶异於中国沿海城市的快速发展，上海的繁华成为耀眼新星。与此同时，同样是在中国，却有这麼个任由艾滋病人凋零的乡间。纪录凉山诺蘇族兄弟在现代化浪潮中，辉煌又惨烈的青春探险，见证了现代与传统、全球与在地、生命与死亡的交织辩证。”

【推荐阅读】刘绍华：从柬埔寨到凉山，观看他人之苦是很难的事[http://www.cnr.cn/shanghai/xyl/20180106/t20180106_524089607.shtml](http://www.cnr.cn/shanghai/xyl/20180106/t20180106_524089607.shtml)

《天真的人类学家》

这本书我也还没读。但是很多人类学书单里都有它，被认为是“诚实而不失风趣”。

“本书诚实但又不失风趣地记录了作为人类学家的作者在非洲喀麦隆多瓦悠人村落两次进行田野工作的经历，将人类学家如何克服乏味、灾难、生病与敌意的真实田野生活拍案叫绝地呈现在读者面前。

不同于一般的人类学研究报告，这是一部令人捧腹不止的人类学笔记，透过幽默的笔调，读者看到了人类学者如何与研究对象进行互动，在互动中如何调整他的学术成见，以及田野工作上的琐事如何影响后来研究结果、研究的盲点与反思。因此不管是严肃的读者、无聊地只想打发时间或者是向往非洲原始部落的异国情调而蠢蠢欲动的旅人，巴利这本书绝对是一个有趣的选择。”——豆瓣

《礼物》莫斯

这本书我还未阅读，属于是经济人类学著作。毕竟莫斯是20世纪法国人类学民族学的代表性人物，又是涂尔干的外甥，全书也只有四章，有兴趣的话可以花点时间看看。

豆瓣评分8.8，简介是“在莫斯对“礼物”的分析中，根本问题是要探究人是如何与物以及通过物而与他人彼此互相关联的。通过对丰富的民族志资料的旁征博引，莫斯提出了以“整体性呈赠”为特征的“礼物经济”的概念，并与现代的、非人格化的商品交换体系相比较，提出了一个三阶段式的演进图式，并进而探讨了物权与契约等经济概念的源起及本质。”

《岂不怀归：三和青年调查》

三和大神指的是在深圳一个叫三和人才市场的地方，有一群外地来打工的年轻人在经历了黑中介和黑厂的坑蒙拐骗之后，索性破罐子破摔，抵制枯燥无味的流水线工作，在三和市场边上混吃等死，干一天玩三天。岂不怀归 出自《诗经》，意思就是“难道我不想家吗”。

最早是2018年，日本NHK电视台的纪录片《三和人才市场 中国日结1500日元的年轻人们》，使得“三和大神”火遍全国。去年，由社科院研究员田丰和社科院2019届硕士研究生林凯玄担纲完成的《岂不怀归》这本书出版。这是国内首部关于“三和大神”的纪实作品，一本生动的社会学白描之作，比起纪录片可能不那么生动，但其中的思考和分析想必更加到位，值得阅读。

《跨越边界的社区》

项飙老师的硕士论文。研究的是北京的“浙江村”，80年代起渐次于北京天安门以南5公里的南苑地 区汇聚成形，属于是一个自组织的移民社区。项飙在90年代于北大求学期间开始对浙江村进行田野。 这本书对“浙江村”的形成、结构、运作、变迁，“浙江村人”作为“外来人口”在北京的生活、生产经营、乡情民愿、与流入地及户籍所在地管理部门的互动等，均加以极近距离的白描式记录、分析。

这本书在2018年出了修订版，豆瓣评分9.4 ，其中的几篇序言很有意义，读前必看。

《像人类学家一样思考》

这本书我完整地阅读了。作者是人类学教授，从事文化人类学导论课程的教学有三十多年。这本书可以说是他总结这么多年教学经验写成的一本导论教材，尤其是每一章的末尾还附有足够数量的练习题供读者进行练习和巩固。

书中每一章开头都以作者自己的田野经历为引子，展开章节主题。内容其实并不艰深，书中举例恰当，易于读者理解一些重要概念。我在书中第一次知道了文化相对主义、反身性、霍桑效应、主客位视角、报道人等概念。很适合作为人类学入门的一本导论书。

《把自己作为方法》

项飙和吴琦的对谈录，之前某段时间成为了畅销书，朋友圈好几位朋友在读。

书中讲到乡绅、中心和边缘、地方最高学府（县中）、人的再生产、主体性，等概念，以及项飙对当下大学的分析与期待。书实际上内容不多，就是个小册子，读起来很快，有时间可以看看。

《摩洛哥田野作业反思》

作者是保罗·拉比诺，格尔茨的学生。他前往摩洛哥进行田野作业，意图完成一次马林诺斯基式的人类学成人礼。不料在这次田野经历中，他却陷入了许多的困惑之中。得益于他接受的哲学思辨教育，他开始对人类学工作的主观和客观、人与非人之矛盾的思考。

拉比诺这本书篇幅不到200页，前面作序的是罗伯特•贝拉，后面写跋的是布尔迪厄，足以证明它的分量。

《村落中的国家：文化变迁中的乡村学校》

作者李书磊。我一开始读到作者把小学说成“国家培育人才的工厂”，后来又看到字里行间是对社会/共产主义社会的剖析，似乎有对中国现行主流教育体制的批判。可是，当我在中文互联网上对本书作者进行检索时，发现现任中央党校常务副校长也叫李书磊，而此书作者的身世几乎不可查。改在维基上检索，这才发现此副校长就是本书作者，在大大任党校校长时他是副手。这让我颇为惊讶，仔细思考之后又觉得合情合理。所以惊讶，是因为体制内人士居然毫不吝啬地批评和揭露体制问题与症结。所以觉得合理，是因为我党高级干部做调查研究，十分近距离地做考察和分析，这本就是自毛时代以来的优良传统。

令人嗟叹的是，书中所描述的如“问答”式教学法、名人崇拜、思想教育渗透、城乡教育差距等问题（此书出版于上世纪末，我推测描写的应该是1998年的情况），在当下是不是依然突出。不知道新任教育部长上任后，中国教育走向何方。书中还分析了乡村现代化，谈到了晏阳初的乡村教育理念和毛泽东对其的效仿。作者是文学博士，对教育工作也有些钻研，但谈论起一个主要是经济与文化内涵的议题就显得有些不太恰切。只作适当参考吧。

整体上，这本书算是一本可读性较高的人类学民族志，其写作笔法甚至可以让一些科班出身的民族志作者汗颜。推荐阅读。

《如何做田野笔记》

这本书的阅读我目前中断了，因为我想以后有了田野作业的机会再读此书，当下阅读的价值不大。这本书“通过大量的正在撰写的、“未完成的”田野笔记实例，考察了田野研究者如何将亲身经历和观察写成田野笔记的过程，讨论如何运用田野笔记来讲述民族志故事的方法，以及帮助研究者基于田野笔记撰写民族志的关键步骤。” 

如果你是准备投入田野、或是即将去到田野，那么推荐你阅读此书，这对于撰写每日手记、田野笔记和最终报告都很有帮助。
